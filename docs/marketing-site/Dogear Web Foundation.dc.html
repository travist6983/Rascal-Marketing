Decisions report — G1 to G7, for approval
G1 · Terracotta contrast HIGH CONFIDENCE
Your 4.25:1 verified against the real tokens (4.36 on surface). Resolution follows the sageInk precedent exactly: terracotta-as-body-text resolves to terracottaDeep #9A431E — 6.31/6.47/5.73, all pass. Buttons keep cream-on-terracotta by setting the label at ≥19px Nunito 700 (WCAG large-text bold), where 4.36 clears the 3:1 bar; anything smaller fills terracottaDeep. Periwinkle checked: 4.73, passes at body size. Derives from: terracottaDeep (existing, "pressed"). No new token.
G2 · Hover HIGH
Web hover maps to what iOS press already does; press keeps the scale. Primary: fill → deep step, 0.12s ease-out; active scale 0.98. Secondary/nav links: inkMuted → ink. Card: shadow 0.04 → 0.07 + 1px rise. Inline link: underline 1px → 2px, terracotta → deep. All from TapScaleButtonStyle (0.98/0.12s) and the pressed colors. Reduced motion: color/shadow changes stay, transforms drop.
G3 · Focus ring HIGH
2px solid periwinkle, 2px offset, on every interactive element via :focus-visible. Periwinkle is the only palette hue clearing 3:1 on every ground it will sit near (canvas 4.73, surface 4.85, every soft fill ≥4.17, wash 4.17). Terracotta was rejected: it reads as "primary action" and sits at 4.25 — fine, but the ring must not look like a state of the button. On a periwinkle-filled control the 2px offset gap of ground provides the separation.
G4 · Breakpoints & grid MEDIUM
393 design base → 600 (phone layout stops here) → 900 (two-column begins) → 1200 (full grid). Max content 1120px. Single column below 600 at 16px margin (the app's screen margin); 8-col/24px gutter at 28px margin to 900; 12-col/32px gutter at 48px margin above. 16/28/48 extends the app's own 16-list / 28-onboarding margin logic.
G5 · Desktop type MEDIUM-HIGH
Three fluid roles, each landing exactly on the app value at 393px: hero 34→64, section 29→44, title 22→28, capped at 1200px. Everything ≤20px stays fixed — prompt body at 20/1.30 is a product voice decision, not a display size. The 64px hero cap is the taste call flagged for your approval.
G6 · Links HIGH
Word in terracottaDeep (G1-compliant, 6.31), underline in base terracotta at 1px, 3px offset — the base hue stays visible as color without carrying text weight. Hover: 2px underline, deepened. Visited: unchanged, deliberately — the palette has no second hue for it and this product does not restyle history. Focus: the G3 ring.
G7 · Form states, no red MEDIUM
Sheet-field dressing (surface, radius 14, border hairline, 12px padding) carried over. Invalid = 2px terracotta border + inkMuted sentence, following the composer's date-provenance precedent ("tinted rather than red, because an absent date is not an error"). Duplicate changes only the sentence. Submitting = disabled treatment (chipPlain/inkFaint) + label swap. Success = sage, because sage is completion. Rendered above, all seven.

  • Hero cap. 64px at 1200px is proposed, not derived — approve or set a number.
